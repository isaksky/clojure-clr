# Plan: Restore Modern .NET AOT Compilation

## High Level Strategy

Use the current `PersistedAssemblyBuilder` path for the first implementation milestone, because the minimal namespace already compiles, source-free loads, and verifies. Keep progressive Clojure load/eval semantics by making eval and persisted generation explicit peers: eval code must remain runnable during compilation, persisted code must remain independent of temporary eval-only types, and every generated type/member reference must resolve through a backend-aware identity map. The Cecil checkpoint has been reassessed after paired generation and remains deferred: current blockers are feature-specific pairing/policy gaps, not a general failure of `PersistedAssemblyBuilder`. Dynamic host interop, `deftype*`/`reify*`, `gen-interface`, `gen-delegate`, `gen-class`, `proxy`, explicit target-framework reference selection, explicit-target custom-attribute metadata, and portable debug symbols now have implemented persisted AOT policies. No open beads remain under this epic.

Decision checkpoint: direct linking is disabled for the first pass with `CLOJURE_COMPILER_DIRECT_LINKING=false`; backend-aware direct-link records are deferred until after the minimal paired-generation path is green.

  First milestone scope: make ordinary namespace AOT reliable for top-level `def`, `defn`, source-free load, top-level `let` lowered through generated function classes, selected generated-form families needed by the runtime namespace tranche, and same-runtime `PersistedAssemblyBuilder` output. The persisted assembly must not reference transient eval-only generated types, and eval code must not depend on persisted generated types while compiling. Dynamic host interop/call-site helpers, `deftype*`, `reify*`, `gen-class`, `proxy`, debug-symbol portability, cross-target reference assembly selection, and Cecil replacement remain outside this first milestone unless a verification fixture proves they are needed earlier.
